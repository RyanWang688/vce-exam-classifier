# VCE 试卷自动分类 Demo

用 Google Gemini 验证 VCE 试卷自动切题和知识点分类的效果。这是一个单文件前端页面（`index.html`），不需要框架和构建工具。

## 本地运行

双击 `index.html` 即可打开。也可以用本地静态服务器：

```bash
python -m http.server 8000
```

```bash
npx serve .
```

然后打开 `http://localhost:8000`（`npx serve` 使用终端显示的地址）。

使用步骤：

1. 在 [Google AI Studio](https://aistudio.google.com/apikey) 创建 API Key，填入页面。
2. 上传 20MB 以内的 PDF、Word，或多张试卷图片，点击“开始分析”。
3. 检查高亮的题目，修改分类并勾选“已确认”。
4. 检查每张自动截图，必要时点“调整”重新框选。
5. 导出 JSON、CSV，或含图片的 ZIP。

> API Key 保存在浏览器 localStorage，**只能用于本地测试**。正式版见 [WIX_GUIDE.md](WIX_GUIDE.md)。

## 哪些题需要复核

模型的自评分数几乎总是很高，所以复核不靠分数，而由页面按规则判定：

- 跨知识点（`topic_fit` 为 `split`，或模型判为 `clear` 却列出了备选知识点）
- 分类表没有合适的知识点（`poor`）或判为 `Other`
- 知识点不在分类表中
- 知识点属于其他 Unit，比如 Unit 3/4 试卷出现 Unit 1/2 内容
- 题目内容可能没读准

勾选“只看需要复核的题”可以只处理这些题。没被标记不代表一定正确：测试中有一道分类表缺项的题就没被标记，所以初期建议抽查。

## 怎么判断 AI 效果

页面顶部的“已确认题 AI 准确率”是已确认的题目中，三个分类字段都没被改动的比例。导出文件保留了 AI 原值（`ai_topic` 等字段），可以用来逐题对比。

## 非 AI 模式

在左上角选择“非 AI 模式”，不需要 Key，不调用任何模型，内容不出浏览器，也没有次数限制。一份 32 页的试卷约 2.5 秒。

| 步骤 | 做法 |
|---|---|
| 切题 | 用文字坐标识别题号、Section、小问、选项和分值；Word 走同一套规则 |
| OCR | 没有文字层的页面用 Tesseract.js 在浏览器里识别，第一次要下载约 10MB 数据 |
| 校验 | 切题结果和封面的题数、总分比对；小问分值之和不等于总分时标记复核 |
| 配图 | 遮掉全部文字和答题线，剩下的图形和表格自动截取 |
| 切题截图 | PDF 和图片的每道题只显示原卷裁图：只含本题，去掉页眉页脚、页码、答题横线和大段空白，跨页的题上下拼接；多题共用的材料（Use the following information…）会放进每道相关题 |
| 后台数据 | 提取的文字不在页面上显示，继续用于分类、题库和导出；Word 没有页面，继续显示文字 |
| 题库 | 分析过的题自动存进浏览器（IndexedDB），页面上汇总各知识点的题数、分值和占比，可导出 JSON / CSV。只存在这台电脑的这个浏览器里，不同步 |
| 分类 | VCE 数学 Unit 3/4 用有序判定规则，从上往下第一条命中为准；大题逐小问判断再按分值投票；General 先按四大板块缩小范围。其他科目用关键词词典 |
| 难度 | VCAA 正式考试（2023–2025）自动取考试报告里每题的得分率：≥ 65% 简单，45%–65% 中等，< 45% 困难。NHT 报告没有统计，NHT 卷和其他试卷由老师标注；老师改过的以老师为准 |
| 组卷 | “组卷”页按科目、时长、知识点、难度比例、题型从题库抽题，可换一批、换一题、删除，打印或存为 PDF。目前只从题库选，AI 补题和仿题是下一阶段 |

PDF 的公式按字形的真实坐标还原成 LaTeX：分数、根号、上下标、积分和求和的上下限、极限、矩阵（含行列标签）、分段函数、向量（波浪号、箭头、导数点）、带边框的表格。公式字体常按页重新编号，有的 PDF 还把 =、−、π、括号画成线条或轮廓，所以符号按字形图像识别。

Word 的公式直接读取原始结构，准确度最高。图片和扫描版的正文用 OCR，公式切成单个字形和字体表比对，再走同样的结构还原，所以分数、根号、上下标大多能排出来，但个别符号会认错。这类题都会标记，公式以截图为准；需要公式完全正确时请用文字版 PDF、Word，或 Gemini 模式。

除了 `Question 1` 格式，也支持校内卷常见的 `Part A: 标题`、`Part A | 标题`、`(a)` 小问和行尾 `[2]` 分值。LaTeX 排版的 PDF 同样可以还原。

能发现的问题会标记“公式请对照截图”，比如无法识别的符号、括号不配对、没用上的分数线、公式解析失败。这些检查不能发现所有错误。图里的坐标和标注不进题干，少量图外的标注可能留下。

**只支持**有 “Question 1” 这种题号的试卷，PDF、Word 和图片都可以。关键词词典主要覆盖数学，理科目前只按知识点名称匹配。

**实测准确率**（40 份 VCAA 数学试卷，详见迭代记录第 26 轮）：切题的总分全部和卷面一致。知识点的盲测结果如下，标准答案由 Claude 按 Study Design 判断，未经老师确认。

| 测试集 | 题数 | 严格（只认一个主知识点） | 宽松（跨知识点的题接受多个合理答案） |
|---|---|---|---|
| 全新盲测（文字版 PDF，10 份） | 189 | 87.3% | 96.3% |
| 第一轮盲测（全是扫描件，6 份，修过后重测，不算真盲测） | 124 | 82.3% | 93.5% |
| 训练用的 24 份（偏高，只作参考） | 500 | 91.2% | 97.2% |

严格口径还没有达到 95%。Methods 的大题最弱，一题常横跨函数、微积分和代数，主知识点本身就有争议。

## 回归检查

修过的问题都写在 `tests/regression.js` 里，改算法后要跑一遍，发现新问题时先加检查再改代码。用法写在文件开头。试卷不进仓库，只放在被忽略的 `tmp-fixtures/`。

## 支持的文件

| 格式 | 配图 | 页码 | 注意 |
|---|---|---|---|
| PDF（文字版、扫描版） | 定位后裁剪 | 有 | 不限制公式类型 |
| Word（`.docx`） | 直接取内嵌图片 | 无 | 见下方 |
| 图片（PNG、JPG、WebP 等） | 定位后裁剪 | 有 | 每张算一页，见下方 |

上传图片时可以一次选多张，页面按文件名的自然顺序排页（`page2` 在 `page10` 前），所以请按顺序命名。大图会缩到长边 2200 像素再发送。iPhone 的 HEIC 不支持，请先转成 JPG。照片模糊、倾斜或有阴影都会影响识别，能用 PDF 时优先用 PDF。

Word 文档有这些限制，遇到时建议另存为 PDF 再上传：

- MathType 等旧式公式读不到内容，Word 自带公式没有问题。
- EMF/WMF 图片、Word 原生形状和图表取不到，可以手动上传替换。
- 脚注不会读取，页眉页脚只读取文字。

旧版 `.doc` 不支持。

## 题目配图

分析分两轮：

1. 第一轮用 PDF 切题分类，同时记录每张图在哪一页。
2. 第二轮用 PDF.js 渲染含图页面，让 Gemini 返回边界框，浏览器再按边界框裁剪。

第二轮每个含图页面发一次请求，这样边界更准，但请求次数较多，用量已计入页面统计。Gemini 免费层按模型计算每日额度，2026-11-06 实测 `gemini-3.6-flash` 每天 20 次请求，在太平洋时间午夜重置（墨尔本时间约晚上 7 点）。一份图多的试卷约需 10 次请求，所以免费层每天大约只够 2 份，批量处理建议开通付费。定位失败不影响分类结果，可以点“重新定位图片”只重跑未完成的页，或手动框选。

- 关闭左侧的“自动截图配图”后，每份试卷只用 1 次请求，配图可以稍后再定位。
- 模型给框后，页面会用 PDF 文字层在本地修正边界，不额外消耗额度。扫描件和图片不做这一步。

| 导出格式 | 图片 |
|---|---|
| JSON | 以 base64 内嵌在 `figures[].image` |
| CSV | 只写文件路径，图片在 ZIP 里 |
| ZIP | `questions.json`、`questions.csv` 和 `figures/` 文件夹 |

截图来自试卷原件，公开使用前请确认版权许可。

## 题目来源

每道题都带来源，方便以后统一入库：

| 字段 | 说明 |
|---|---|
| `source_id` | 题目唯一 ID，由出版方、年份、试卷名、类型、Section 和题号生成 |
| `source.label` | 给人看的来源，如 `2024 VCAA Physics Written Examination Section B Q1` |
| `source.publisher` / `paper_title` / `paper_type` / `year` | 可筛选的结构化字段 |
| `source.page` | 题目在 PDF 里的起始页 |
| `source.adapted_from` | 卷面标注的改编来源，如 `2022 SM Exam 1` |
| `source.file` / `file_sha256` | 原文件名和文件指纹，用于追溯和识别重复文件 |

AI 识别的来源可以在结果页修改，修改会应用到全部题目。修改会改变 `source_id`，请在入库前确认好。

## 分类表来源

分类表来自 VCAA Study Design（Mathematics 2023 起，Physics 和 Chemistry 的 Units 3/4 2024 起，Biology 2022 起）：

| 科目 | 范围 |
|---|---|
| Foundation、General、Methods、Specialist Mathematics | Units 1/2 和 3/4 |
| Chemistry、Physics、Biology | Units 3/4 |

- 有内容小标题的知识点使用原文；Foundation 和 Methods 原文大多只到 Area of Study。
- Mathematical Methods Units 3/4 的微积分和概率统计，是按文档内容再细分的。
- `Hypothesis testing for a population mean` 是原标题的缩写。

如果你在页面上改过分类表，浏览器会继续使用你的版本。想用新版请点“恢复默认”。
